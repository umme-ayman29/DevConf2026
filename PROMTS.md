# AI Prompts Used

## Prompt 1

Create a unique HTML and CSS section for a DevConf 2026 landing page.

The section should be relevant to a technology conference and different from the required sections.

Create a "Tech Pulse" section that shows which technology topics attendees are most excited about.

Include:
- A section heading
- A short description
- Five technology topics
- Percentage values
- Animated progress bars using only HTML and CSS
- A modern dark theme that matches the overall DevConf website
- No JavaScript
- Clean, semantic HTML and organized CSS

I customized the generated code and styling to match the overall design of my project.
